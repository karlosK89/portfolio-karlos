# Portfolio Karlos

Portfolio statique en HTML / CSS / JavaScript.

## Structure

- `index.html` : page principale
- `css/styles.css` : styles
- `js/main.js` : menu mobile + année automatique
- `projects/` : pages détaillées des quatre projets
- `assets/img/` : illustrations de remplacement

## Utilisation

1. Ouvre le dossier dans VS Code.
2. Ouvre `index.html` dans ton navigateur.
3. Idéalement, utilise l'extension **Live Server** dans VS Code.
4. Remplace la section Contact par tes propres liens lorsque tu seras prêt à publier.
5. Plus tard, tu pourras ajouter une section Data / Business Intelligence au-dessus des projets web.

## Important

Les illustrations présentes dans `assets/img/` ne sont pas des captures des anciens projets.
Elles sont volontairement identifiées comme des visuels de portfolio, car les fichiers originaux ne sont plus disponibles.

## Publication

Le site peut être publié gratuitement avec GitHub Pages, Netlify ou Vercel.
