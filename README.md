# Portfolio Karlos — V2

Cette version a volontairement été construite avec du code simple.

## Fichiers

- `index.html` : tout le contenu du portfolio
- `css/style.css` : toute la mise en page et les animations
- `js/script.js` : seulement 3 petites fonctions
- `assets/img/` : visuels des projets

## Le JavaScript fait seulement 3 choses

1. Ouvrir / fermer le menu sur mobile.
2. Faire apparaître les sections au scroll.
3. Afficher automatiquement l'année actuelle.

## Pourquoi utiliser `<details>` ?

Les boutons "Voir les détails" utilisent la balise HTML native `<details>`.
Cela permet d'avoir une interaction sans écrire de JavaScript supplémentaire.

## Pour tester

Ouvre le dossier dans VS Code puis lance `index.html` avec Live Server.
