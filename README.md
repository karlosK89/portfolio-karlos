# Portfolio — Karlos Zaghbour

Portfolio personnel réalisé en **HTML, CSS et JavaScript**.

## Objectif

Présenter de manière simple et accessible quelques projets réalisés pendant ma formation en développement web ainsi qu'une expérience pratique en environnement professionnel.

## Technologies présentées

- HTML / CSS / SCSS
- Bootstrap
- JavaScript / jQuery / AJAX
- PHP
- WordPress / Elementor
- Laravel
- MySQL / MariaDB
- Git / GitHub

## Structure du projet

- `index.html` : page principale
- `css/style.css` : styles et responsive
- `js/script.js` : menu mobile, animation au scroll et année automatique
- `assets/img/` : visuels de présentation des projets
